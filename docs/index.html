What is mkvis3d?

mkvis3d (package name openbiomech) is an open-source, reproducible alternative to C-Motion Visual3D and BTK Mokka: a C3D/CSV/.3d motion viewer plus the underlying biomechanics math (rigid-body registration, filtering, ISB joint kinematics, body segment parameters, gait events, inverse dynamics with force plates). It is developed as a companion project to vailá — Multimodal Toolbox and is intended to eventually be integrated into it as vailá's 3D viewer / biomechanics-core module — see the README's "Relationship to vailá" section.

Project phase

The project is in the Python prototype phase: the core math is implemented and tested in Python (openbiomech/), reusing code already tested in production by vailá, before porting to the long-term Rust workspace described in architecture.html. See the status table in the README for which parts are done.
