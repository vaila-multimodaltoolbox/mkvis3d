mkvis3d — User Manual & Biomechanics Theory Guide

Welcome to mkvis3d (package openbiomech), a reproducible, open-source biomechanical analysis suite and 3D motion viewer designed as a high-performance, modern alternative to C-Motion Visual3D, BTK Mokka, and Kwon3D.

Key Capabilities

  • Complete C3D I/O: Reads and writes binary C3D files (Intel, DEC VAX, MIPS; float and integer) preserving 3D markers, analog force channels, EMG, and parameter groups.
  • Cartesian Bases (s1, s2, sg): 3-point segment coordinate system construction with strict Gram-Schmidt orthonormalization.
  • Live Relative Kinematics: Real-time rotation matrix MR = sg · s1^T · s2 · sg^T, Cardan/Euler angles across all 6 Tait-Bryan sequences, and scalar-first quaternions.
  • Virtual Point Creator: Create anatomical joint centers using standard NumPy vector syntax with reusable pipeline scripts.
  • Signal Conditioning: Zero-phase 4th-order Butterworth low-pass filtering and 1-click PCHIP monotonic gap filling.
  • Kinetics: Types 1–5 force platform calibration, Center of Pressure (COP), and bottom-up recursive Newton-Euler inverse dynamics.

2. Biomechanical Coordinate Systems & Orthonormal Bases

In classical motion analysis (Kwon3D, Visual3D, ISB), defining segment movement requires constructing Local Segment Coordinate Systems (LCS / SCS) and relating them to the Global Reference System (GRF).

2.1 Global System (sg) vs Local Systems (s1, s2)

  • Global Reference System (sg): The laboratory world frame. By default, it is the canonical 3x3 identity matrix [I 3x3] (where Z is Vertical Up, X is Anterior, Y is Lateral).
  • Proximal System (s1): The local coordinate system of the parent segment (e.g. Pelvis or Thigh).
  • Distal System (s2): The local coordinate system of the child segment (e.g. Thigh or Shank).

2.2 3-Point Basis Construction & Gram-Schmidt Orthonormalization

A Cartesian basis is built from three non-collinear markers: Origin (r_orig), Primary Axis (r_prim), and Plane Point (r_plane):

v_prim = r_prim - r_orig
v_plane = r_plane - r_orig
e_prim = v_prim / ||v_prim||
v_ortho = v_plane - (v_plane · e_prim) e_prim
e_sec = v_ortho / ||v_ortho||
e_tert = e_prim × e_sec

Each axis versor is explicitly divided by its Euclidean norm. mkvis3d strictly verifies that:
✓ ||ex|| = 1.000, ||ey|| = 1.000, ||ez|| = 1.000
✓ Mutual 90.0° orthogonality: ei · ej = 0
✓ Right-handed parity: det([ex, ey, ez]) = +1.000

3. Relative Joint Kinematics (MR, Cardan/Euler & Quaternions)

The relative joint rotation matrix expressing the distal segment (s2) in the proximal segment frame (s1), transformed through the laboratory reference frame (sg), is computed live at every frame:

MR2 = sg · s1^T
MR = (MR2 · s2) · sg^T = sg · s1^T · s2 · sg^T

3.1 Tait-Bryan / Cardan Angle Extraction

mkvis3d decomposes MR into clinical anatomical angles across all 6 Tait-Bryan sequences (zxy, xyz, zyx, yxz, xzy, yzx):

  • Angle 1 (α): Flexion (+) / Extension (−) [Sagittal plane]
  • Angle 2 (β): Abduction (+) / Adduction (−) [Coronal plane]
  • Angle 3 (γ): Internal (+) / External (−) Rotation [Axial plane]

3.2 Scalar-First Unit Quaternions

To avoid gimbal lock singularities, orientation is continuously tracked using scalar-first unit quaternions:

q = (w, x, y, z), where ||q|| = √(w² + x² + y² + z²) = 1.0

4. Virtual Points & Secondary Landmark Creator

Anatomical joint centers cannot be measured directly on skin surfaces. mkvis3d allows creating secondary virtual points using NumPy vector syntax in the dedicated modal:

Common Formula Examples:

1. Midpoint of two markers (e.g. Pelvis center):

(p['RASI'] + p['LASI']) / 2

2. Normal perpendicular vector (via cross product):

np.cross(p['p2'] - p['p1'], p['p3'] - p['p1'])

3. Anatomical offset from bony landmark:

p['KNEE_LAT'] + 0.05 * (p['KNEE_MED'] - p['KNEE_LAT'])

5. Signal Conditioning: Filtering & Gap Interpolation

5.1 Butterworth Dual-Pass Filter

A 4th-order zero-phase Butterworth low-pass filter (forward-backward dual-pass) eliminates high-frequency marker noise without phase distortion. Cutoff frequencies are automatically corrected for dual-pass attenuation per Winter (1990).

5.2 1-Click Gap Interpolation

Missing or occluded marker frames (NaN) are highlighted on the timeline with Visual3D-style shaded bands. Users can fill gaps with a single click using:

  • Cubic Spline (PCHIP): Shape-preserving piecewise cubic Hermite spline that avoids overshoots.
  • Linear: Direct linear segment interpolation.
  • ↩ Revert: Non-destructive backup allows restoring raw missing frames at any time.

6. Anthropometry & Whole-Body Center of Mass (de Leva 1996)

mkvis3d implements the validated 16-segment de Leva (1996) model. Mass fractions and longitudinal CoM positions are adjusted for biological sex:

r_CoM(t) = (1 / M_total) · ∑ [ m_i · r_i,CoM(t) ]

Clicking Create CoM adds a live 3D visual marker tracking whole-body CoM throughout the motion.

7. Force Platforms, Ground Reaction Forces & Kinetics

  • Calibration & COP: Supports Types 1–5 platforms using 6x6 calibration matrices and geometric sensor origin corrections.
  • Vertical Threshold: Automatically hides COP and GRF vectors below 15 N to avoid non-contact singularities.
  • 3D Vectors: Renders real-time ground reaction force arrows with dynamic color scaling and magnitude readouts.

8. Workspace Visualization & Multi-Window Navigation

mkvis3d provides a flexible multi-window desktop interface:

  • Multi-Monitor Popout (⧉): Detach 3D Viewport, Plots, Table, or Video into independent windows.
  • Fast 3D Viewport Refresh (↻): Drops GPU compositor surfaces, recalculates bounds, and resets camera.
  • Reference Video Sync: Syncs high-speed video frames directly with 3D marker cloud trajectories.

9. Data Export, Pipelines & CLI Automation

  • Standalone HTML: Self-contained offline viewer viewable on any computer without software installation.
  • C3D Export: Exports edited trajectories while preserving synchronized analog force plate and EMG signals.
  • Blender Script: Generates Python script for photorealistic rendering in Blender Cycles/Eevee.
  • Python Pipeline (.py): Generates standalone script replicating all virtual points and Cartesian bases.
