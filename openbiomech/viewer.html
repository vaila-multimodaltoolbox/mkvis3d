1. Overview & Architecture

Welcome to mkvis3d (package openbiomech), a reproducible, open-source biomechanical analysis suite and 3D motion viewer designed as a high-performance, modern alternative to C-Motion Visual3D, BTK Mokka, and Kwon3D.

Key Capabilities:

  • Complete C3D I/O: Reads/writes binary C3D files (Intel, DEC VAX, MIPS) with 3D markers, analog force plates, EMG, and parameter groups.
  • Cartesian Bases (s1, s2, sg): 3-point segment coordinate system construction with Gram-Schmidt orthonormalization.
  • Live Relative Kinematics: Live rotation matrix MR = sg · s1^T · s2 · sg^T, Cardan/Euler angles across all 6 Tait-Bryan sequences, and scalar-first quaternions.
  • Virtual Points Creator: NumPy vector formulas for secondary landmarks with exportable Python pipeline scripts.
  • Signal Conditioning: 4th-order zero-phase Butterworth filter and 1-click PCHIP monotonic gap interpolation.
  • Kinetics: Types 1–5 calibration, COP, and bottom-up Newton-Euler inverse dynamics.

2. Biomechanical Coordinate Systems & Orthonormal Bases

In biomechanics and human movement analysis (Kwon3D, Visual3D, ISB standards), analyzing 3D joint motion requires setting up Local Segment Coordinate Systems (LCS / SCS) and referencing them to the Global Reference System (GRF).

2.1 Global System (sg) vs Local Systems (s1, s2)

  • Global Reference System (sg): Laboratory world frame. Canonical 3×3 identity matrix [I 3x3] (Z Vertical Up, X Anterior, Y Lateral).
  • Proximal Segment (s1): Coordinate system of parent segment (e.g. Pelvis or Thigh).
  • Distal Segment (s2): Coordinate system of child segment (e.g. Thigh or Shank).

2.2 3-Point Basis Construction & Gram-Schmidt Orthonormalization

Built from 3 non-collinear markers: Origin (r_orig), Primary Point (r_prim), and Plane Point (r_plane):

v_prim = r_prim - r_orig
v_plane = r_plane - r_orig
e_prim = v_prim / ||v_prim||
v_ortho = v_plane - (v_plane · e_prim) e_prim
e_sec = v_ortho / ||v_ortho||
e_tert = e_prim × e_sec

Each axis is divided by its Euclidean norm (||e|| = 1.0). mkvis3d verifies:
✓ Unit norm: ||ex|| = 1.000, ||ey|| = 1.000, ||ez|| = 1.000
✓ Orthogonality: 90.0° between all axis pairs (ei · ej = 0)
✓ Right-handed chirality: det([ex, ey, ez]) = +1.000

3. Relative Joint Kinematics (MR, Cardan/Euler & Quaternions)

The relative joint rotation matrix expressing distal segment s2 in proximal segment s1, transformed through the laboratory reference frame sg, is calculated live:

MR2 = sg · s1^T
MR = (MR2 · s2) · sg^T = sg · s1^T · s2 · sg^T

3.1 Tait-Bryan / Cardan Sequences

mkvis3d decomposes MR into clinical anatomical angles across 6 sequences (zxy, xyz, zyx, yxz, xzy, yzx):

  • Angle 1 (α): Flexion (+) / Extension (−) [Sagittal plane]
  • Angle 2 (β): Abduction (+) / Adduction (−) [Coronal plane]
  • Angle 3 (γ): Internal (+) / External (−) Rotation [Transverse plane]

3.2 Scalar-First Quaternions

Singularity-free orientation representation:

q = (w, x, y, z), where ||q|| = √(w² + x² + y² + z²) = 1.0

4. Virtual Points & Secondary Landmark Creator

Create unlimited secondary anatomical joint centers directly using standard NumPy vector expressions:

1. Midpoint of two markers (Pelvis center):

(p['RASI'] + p['LASI']) / 2

2. Offset along anatomical axis:

p['KNEE_LAT'] + 0.05 * (p['KNEE_MED'] - p['KNEE_LAT'])

3. Vector cross product:

np.cross(p['p2'] - p['p1'], p['p3'] - p['p1'])

5. Signal Conditioning: Filtering & Gap Interpolation

5.1 Butterworth Dual-Pass Filter

4th-order zero-phase lowpass Butterworth filter (forward-backward dual pass). Eliminates phase shift with cutoff frequency correction factor C = (2^(1/4) - 1)^(1/4) ≈ 0.802.

5.2 1-Click Gap Interpolation

Missing frames (NaN) appear as shaded warning zones on coordinate timelines. Select a marker and click ✨ Fill Missing Gaps to apply shape-preserving PCHIP cubic interpolation or linear filling. Non-destructive backup allows clicking ↩ Revert to Raw at any time.

6. Anthropometry & Whole-Body Center of Mass (de Leva 1996)

Validated 16-segment de Leva (1996) model adjustments for males and females:

r_CoM(t) = (1 / M_total) · ∑ [ m_i · r_i,CoM(t) ]

Renders a live 3D CoM marker and provides trajectory coordinates for equilibrium and postural stability analysis.

7. Force Platforms, Ground Reaction Forces & Kinetics

  • Types 1–5 Calibration: Automatic detection and application of 6×6 calibration matrices and origin offsets.
  • Center of Pressure (COP): Calculates dynamic instantaneous COP during ground contact.
  • Thresholding: Forces below 15 N are automatically hidden to prevent baseline noise artifacts.
  • 3D Vectors: Real-time rendering of force vectors in the 3D scene with dynamic length and color scaling.

8. Workspace Visualization & Multi-Window Navigation

  • Multi-Monitor Popout (⧉): Detach 3D Viewport, Plots, Table, or Video into independent windows.
  • Fast 3D Viewport Refresh (↻): Drops GPU compositor surfaces, recalculates bounds, and resets camera.
  • Reference Video Sync: Syncs high-speed video frames directly with 3D marker cloud trajectories.

9. Data Export, Pipelines & CLI Automation

  • Standalone HTML: Self-contained offline viewer viewable on any computer without software installation.
  • C3D Export: Exports edited trajectories while preserving synchronized analog force plate and EMG signals.
  • Blender Script: Generates Python script for photorealistic rendering in Blender Cycles/Eevee.
  • Python Pipeline (.py): Generates standalone script replicating all virtual points and Cartesian bases.
