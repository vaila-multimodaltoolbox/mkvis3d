Visual3D Laboratory Coordinate System (LCS)

Configure laboratory orientation following the Visual3D Set_Laboratory_Coordinate_System standard. Fix trials where Y is vertical (BVH, Unity, 3D CSV) or walkway direction is along X.

Computed ML (Right / Lateral): +X
Orientation / Handedness: Right-Handed System (det = +1.0)
