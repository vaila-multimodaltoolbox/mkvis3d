# Workspace Guidelines

- **Autonomia e Confirmações**: Execute edições, testes e modificações diretamente sem solicitar confirmação manual ("Do you want to proceed?"). O padrão deve ser sempre `yes` (prosseguir automaticamente).
- **Controle de Versão (Git)**: NÃO execute `git add`, `git commit`, `git push` ou operações de versionamento ao finalizar tarefas. Deixe todas as operações de commit e push exclusivamente para o usuário.
