1. System Overview & Architecture

mkvis3d (package openbiomech) is a reproducible, open-source biomechanical analysis suite and 3D motion viewer designed for researchers, clinicians, and sports scientists. It runs locally without cloud dependencies, ensuring complete data privacy and high performance.

Core Functional Pillars:

  • Binary C3D & Mocap I/O: Native decoding and encoding of 3D marker cloud trajectories, analog force plates, and EMG channels across Intel, DEC, and MIPS architectures.
  • Cartesian Bases ($s_1, s_2, s_g$): 3-point segment coordinate system construction with strict Gram-Schmidt orthonormalization.
  • Relative Joint Kinematics: Real-time joint rotation matrix $MR = s_g s_1^T s_2 s_g^T$, Cardan/Euler decomposition (6 sequences), and scalar-first unit quaternions.
  • Secondary Landmark Synthesizer: Dynamic virtual point creator using standard NumPy vector syntax with exportable pipeline scripts.
  • Signal Conditioning: 4th-order zero-phase low-pass Butterworth filtering with dual-pass attenuation correction, Hampel outlier detection, and shape-preserving PCHIP cubic gap interpolation.
  • Kinetics & Force Plates: Types 1–5 calibration matrix support, dynamic Center of Pressure (COP), 15 N contact thresholding, and bottom-up recursive Newton-Euler inverse dynamics.

2. Data Formats & Biomechanical I/O

mkvis3d supports industry-standard motion capture and biomechanical exchange formats:

  • C3D (.c3d): Binary standard preserving 3D point coordinates, analog channels, sampling frequencies, video sync frame ratios, and parameter groups (POINT, ANALOG, FORCE_PLATFORM). Supports both float32 and integer data formats across Little-Endian and Big-Endian architectures.
    • Save As (C3D)... (Ctrl+Shift+S): Prompts for a new target filename (preserving original file) with edited markers, gap-fills, and virtual points.
    • Quick Save C3D: Quickly saves to <stem>_edited.c3d.
    • Sample Trials Submenu: Built-in demonstration files are grouped in a compact flyout menu (File ▾ 📁 Sample Trials ▸).
  • CSV (.csv): Universal tabular format containing frame index, time (s), and 3D coordinate columns (X, Y, Z) per marker.
  • Raw 3D (.3d): ASCII and binary 3D trajectory data formats.
  • Project Session State (.vaila): Complete JSON-encoded project file capturing current camera view, active marker, selected skeletons, custom virtual points, filter parameters, and LCS definitions.
  • Biovision Hierarchy (.bvh): Standard skeletal animation file containing hierarchical bone offsets and continuous Euler joint rotations.
  • Blender Python Script (.py): Fully automated script for photorealistic rendering in Blender (Cycles/Eevee) with material shaders, armatures, and keyframed trajectories.

5. Point Selection, 3D Distance & Vector Angle Measurement

mkvis3d provides comprehensive Euclidean distance and spatial vector angle measurement tools with real-time 3D viewport rendering and continuous timeline plotting.

5.1 3D Euclidean Distance

d(t) = √((x_B(t) - x_A(t))² + (y_B(t) - y_A(t))² + (z_B(t) - z_A(t))²)
  • Select Marker A and Marker B from the sidebar dropdowns.
  • Renders a live connecting 3D line between the two markers in the viewport (color-coded amber).
  • Generates a dynamic distance timeline curve on Plot 1 with instantaneous readout in meters.
  • Calculates summary statistics: Minimum, Maximum, Mean, and Standard Deviation across the trial.

5.2 Vector Angle via Dot Product

Spatial angles between two 3D vectors are calculated using the vector dot product, with strict numerical clamping to [-1.0, 1.0] to prevent floating-point precision NaN values:

u · v = ||u|| ||v|| cos(θ)
cos(θ) = (u · v) / (||u|| ||v||)
θ = arccos(clamp(cos(θ), -1.0, 1.0)) × (180° / π)
  • 3 Markers (Vertex Mode): Measures joint angles (e.g. Hip-Knee-Ankle). Given Marker A, Vertex Marker B, and Marker C, the two vectors share origin B:
    u = A - B, v = C - B
  • 4 Markers (Independent Vectors): Measures the spatial orientation between two separate segments or axes:
    u = B - A (Vector 1), v = D - C (Vector 2)
  • 3D Viewport Visualization: Draws Vector 1 in Cyan, Vector 2 in Amber, an arc around the vertex, and a live 3D billboard text badge with θ = XX.X°.
  • Timeline Multi-Plot: Plot 1 and Plot 2 can display continuous Angle (Dot Product °) curves across all frames with NaN gap bands and range of motion (ROM) metrics.

6. Coordinate Systems & Orthonormal Bases (sg, s1, s2)

In biomechanics and human movement analysis, joint kinematics require defining Local Segment Coordinate Systems (LCS / SCS) and referencing them to the Global Reference System (GRF).

6.1 System Definitions

  • Global Reference System (sg): Laboratory world coordinate system. Canonical 3×3 identity matrix [I 3×3] where Z is Vertical Up, X is Anterior, and Y is Lateral.
  • Proximal System (s1): Local coordinate system of the parent segment (e.g. Pelvis or Thigh).
  • Distal System (s2): Local coordinate system of the child segment (e.g. Thigh or Shank).

6.2 3-Point Basis Construction & Gram-Schmidt Orthonormalization

Each basis is built from three non-collinear markers: Origin (r_orig), Primary Point (r_prim), and Plane Point (r_plane):

v_prim = r_prim - r_orig
v_plane = r_plane - r_orig
e_prim = v_prim / ||v_prim||
v_ortho = v_plane - (v_plane · e_prim) e_prim
e_sec = v_ortho / ||v_ortho||
e_tert = e_prim × e_sec

Every axis is strictly normalized by its Euclidean norm. mkvis3d verifies in real time:
✓ Unit norm: ||ex|| = 1.000, ||ey|| = 1.000, ||ez|| = 1.000
✓ Mutual orthogonality: 90.0° between all axis pairs (ei · ej = 0)
✓ Right-handed chirality: det([ex, ey, ez]) = +1.000

6.3 Left-Hand Rule Mnemonic & Right-Hand Cross-Product Mathematics

In standard biomechanics and 3D modeling (such as Blender 3D), global coordinate frames follow the intuitive Left-Hand Rule mnemonic:
• Middle Finger: +X axis (pointing Right / Lateral)
• Index Finger: +Y axis (pointing Forward / Walkway progression)
• Thumb: +Z axis (pointing Vertically Upward)

Z = X × Y,   X = Y × Z,   Y = Z × X,   det(R) = +1.0

In the Reference System & Origin (LCS) modal (Alt+L), use 1-click tools: Auto Z = X × Y, Auto X = Y × Z, Auto Y = Z × X, and Enforce Right-Handed (det = +1.0) to ensure proper physical chirality.

6.4 Vision AI / Monocular 3D Quick Conversion (vailá Toolbox)

7. Relative Joint Kinematics (MR, Cardan/Euler & Quaternions)

Use Analysis for segment bases, reference system and origin, virtual points, filtering, and timeline curves. Attach analysis JSON/CSV and export results from File.

The relative joint rotation matrix expressing distal segment s2 in proximal segment s1, transformed through the laboratory reference frame sg, is calculated live at every frame:

MR2 = sg · s1^T
MR = (MR2 · s2) · sg^T = sg · s1^T · s2 · sg^T

7.1 Cardan / Euler Angle Sequences

mkvis3d decomposes MR into clinical anatomical angles across all 6 Tait-Bryan sequences:

  • Z-X-Y (ISB Standard for Knee & Hip):
    • α (Z-axis): Flexion (+) / Extension (−) [Sagittal plane]
    • β (X-axis): Adduction (+) / Abduction (−) [Coronal plane]
    • γ (Y-axis): Internal (+) / External (−) Rotation [Transverse plane]
  • X-Y-Z (Cardan Standard): Flexion → Abduction → Rotation.
  • Z-Y-X (Aerospace / Nautical): Yaw → Pitch → Roll.
  • Y-X-Z, X-Z-Y, Y-Z-X: Additional permutations available via the sequence dropdown.

7.2 Scalar-First Unit Quaternions

To avoid gimbal lock singularities, relative orientation is continuously parameterized using scalar-first quaternions:

q = (w, x, y, z), where ||q|| = √(w² + x² + y² + z²) = 1.0000

8. Virtual Points, CSV Trajectories & Trajectory Editing

Joint centers (e.g. Hip Joint Center, Knee Joint Center), calibration offsets, and externally filtered/reconstructed trajectories can be seamlessly integrated into mkvis3d. The platform provides three specialized creation and editing workflows:

8.1 NumPy Formula Mode

Create dynamic virtual points evaluated across all trial frames using NumPy syntax:

1. Midpoint of two markers (e.g. Pelvis center):

(p['RASI'] + p['LASI']) / 2

2. Offset along anatomical axis (e.g. Knee center):

p['KNEE_LAT'] + 0.05 * (p['KNEE_MED'] - p['KNEE_LAT'])

3. Vector translation:

p['A'] + (p['B'] - p['C'])

4. Perpendicular vector via cross product:

np.cross(p['p2'] - p['p1'], p['p3'] - p['p1'])

8.2 Manual Coordinates Mode (X, Y, Z)

Define static or calibration points by directly specifying fixed metric coordinates [X, Y, Z]:

  • Enter numerical values for X (m), Y (m), and Z (m) directly in the input boxes.
  • Click 📋 Copy from Active Marker @ Frame to immediately fill the inputs with the 3D position of the selected marker at the current playback time.
  • Press + Create Point to instantiate the point across all frames. In the defined points list, it appears as 📍 Manual [X, Y, Z] m.

8.3 CSV Trajectory Matrix Mode (Import & Replace)

Import external time-series coordinate matrices from CSV/text files (rows = time frames, columns = coordinates in meters):

  • Supported Column Structures: 3 columns (X, Y, Z), 4 columns (frame, X, Y, Z or time, X, Y, Z), or 5 columns (frame, time, X, Y, Z). Automatic separator detection (,, ;, \t, space) and header recognition.
  • Destination Action:
    • Create as New Point: Registers the imported trajectory as a new marker/point (e.g., P_FILTERED). It immediately appears in the 3D scene, timeline plots, and kinematics calculators.
    • ↻ Replace Existing Marker: Replaces the trajectory of an existing physical marker in-place. The 3D animation, coordinate system segments, and curves instantly update while caching original raw data.

8.4 Marker Trajectory Cleaning & Gap Blanking

Remove erroneous frames or marker reflection artifacts by setting them to NaN gaps before running filters or interpolations:

  • Current Playback Frame: Instantly blanks the selected marker's coordinates at the current paused frame.
  • Frame Range (From ... To ...): Blanks a contiguous sequence of frames (e.g., frames 120 to 180).
  • CSV Frame List File: Upload a CSV or text file containing frame indices or intervals (e.g. 12, 13, 20-35) to blank in batch.
  • Blank All Frames: Clears the entire trajectory to NaN.
  • ↩ Restore Marker Raw Data: Non-destructive 1-click recovery that resets any replaced or blanked marker back to its raw imported state.

8.5 External Roundtrip Workflow

Export marker trajectories (File ▾ -> Export Active Marker (CSV)... or [📥 Export CSV]), process them in Python, MATLAB, or R, and reload them via File ▾ -> Import / Replace Marker Trajectory (CSV)....

9. Signal Conditioning: Filtering & Gap Interpolation

9.1 Hampel Outlier Detection Filter

Detects and removes sensor spikes using a sliding window and Median Absolute Deviation (MAD):

MAD = median(|x_i - median(x)|), |x_i - median(x)| > 3.0 × 1.4826 · MAD

9.2 Gap Filling Algorithms

  • Cubic Spline (PCHIP): Shape-preserving Piecewise Cubic Hermite Interpolation. Prevents unphysical overshoots while preserving signal monotonicity.
  • Linear Interpolation: Direct linear segment filling.
  • Nearest Neighbor & Kalman: Constant-velocity state prediction for occluded markers.
  • Max Gap Threshold: Limits filling to gaps below specified duration (e.g. 10 frames).

9.3 Zero-Phase Butterworth Lowpass Filter

4th-order zero-phase Butterworth filter (forward-backward dual pass) eliminating phase delay. The cutoff frequency f_c is adjusted for dual-pass attenuation per Winter (1990):

C = (2^(1/4) - 1)^(1/4) ≈ 0.801968, f_c,adjusted = f_c / C

10. Anthropometry & Whole-Body Center of Mass (de Leva 1996)

mkvis3d implements the validated 16-segment de Leva (1996) body segment parameter model with sex-specific mass fractions and longitudinal CoM positions:

r_CoM(t) = (1 / M_total) · ∑ [ m_i · r_i,CoM(t) ]
  • 16 Segments: Head, Upper Trunk, Mid Trunk, Lower Trunk, Thigh (L/R), Shank (L/R), Foot (L/R), Upper Arm (L/R), Forearm (L/R), Hand (L/R).
  • Sex Adjustments: Accounts for differences in pelvic morphology and mass distribution between males and females.
  • Live 3D Visualization: Displays instantaneous CoM sphere and projected floor intersection for balance and postural stability assessment.

11. Force Platforms, Ground Reaction Forces & Kinetics

11.1 Force Platform Calibration (Types 1–5)

Decodes and applies 6x6 calibration matrices and sensor geometric origin offsets (x_0, y_0, z_0) across all standard AMTI, Kistler, and Bertec plate configurations.

11.2 Center of Pressure (COP)

x_cop = (-M_y + F_x · z_0) / F_z + x_0, y_cop = (M_x + F_y · z_0) / F_z + y_0

Contact Threshold: Forces below 15 N are automatically thresholded to eliminate non-contact division-by-zero noise.

11.3 Bottom-Up Recursive Newton-Euler Inverse Dynamics

F_joint = m · a_cm - F_ext - m · g
M_joint = I · ω_dot + ω × (I · ω) - M_ext - (r_p × F_p) - (r_d × F_d)
P_joint = F_joint · v_joint + M_joint · ω_rel
